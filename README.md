# bt-toggle

Утилита для Windows: подключать и отключать Bluetooth-наушники одним кликом по иконке в трее.

## Использование

- Правый клик по иконке: выбрать устройство, включить «Запускать при входе в Windows», выйти.
- Левый клик: подключить или отключить выбранное устройство.
- Цвет иконки: серая — отключено, жёлтая — подключаю, голубая — подключено. В тултипе имя и заряд.
- Полоска справа от наушников — заряд: зелёная от 40%, жёлтая ниже 40, оранжевая ниже 30, красная ниже 20.
- Если устройство не подключилось за 15 секунд, приходит уведомление Windows.
- Список устройств в меню обновляется сам, когда сопрягается новое устройство или удаляется старое.

Настройки лежат в `HKCU\Software\bt-toggle`. Автозапуск — значение `bt-toggle` в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`; оно указывает на exe, из которого включили галочку.

## Сборка

```powershell
cargo build --release   # target\release\bt-toggle.exe
```

Установка или обновление (сначала выйди из запущенного трея):

```powershell
$dir = "$env:LOCALAPPDATA\Programs\bt-toggle"
New-Item -ItemType Directory -Force $dir | Out-Null
Copy-Item .\target\release\bt-toggle.exe $dir -Force
Start-Process "$dir\bt-toggle.exe"   # затем включи автозапуск в меню
```

## Как это устроено

**Подключение.** Для каждого аудиовыхода (воспроизведение и запись) утилита идёт по топологии устройства до KS-фильтра Bluetooth-драйвера (`bthenum` — A2DP, `bthhfenum` — Hands-Free). Затем шлёт ему `KSPROPERTY_ONESHOT_RECONNECT` / `KSPROPERTY_ONESHOT_DISCONNECT` из набора `KSPROPSETID_BtAudio`. Это тот же механизм, которым пользуется Windows. Подход взят из [ToothTray](https://github.com/m2jean/ToothTray) (BSD-2).

Hands-Free может быть доступен только через выход записи (микрофон). Если перебирать одни выходы воспроизведения, как ToothTray, профиль HFP остаётся подключённым. Тогда звук пропадает, а Windows продолжает считать наушники подключёнными.

**Имя и заряд.** Берутся из узлов `BTHENUM`, найденных через SetupAPI по ContainerId аудиовыходов. Имя — с узла самого устройства `BTHENUM\DEV_<адрес>`. Заряд — свойство `{104EA319-6EE2-4701-BD47-8DDBF425BBE5} 2` (байт, проценты) на узле Hands-Free AG; это значение показывают «Параметры → Bluetooth».

**Состояние** опрашивается раз в секунду.

## Проверено

Sony WH-1000XM4, Windows 11, 2026-10-14:

- после отключения утилитой все аудиовыходы переходят в `Unknown`, Windows показывает наушники отключёнными;
- после этого наушники подключаются и утилитой, и штатно через Win+A, воспроизведение продолжается на наушниках;
- в тултипе тот же заряд, что в «Параметрах»;
- для недоступного устройства (выключенная колонка) через 15 секунд приходит уведомление;
- галочка автозапуска записывает значение в `Run`.

## Не сделано

Хоткей, несколько избранных устройств, переключение устройства вывода звука, инсталлятор, подпись, winget.

## Благодарности и предшественники

- [ToothTray](https://github.com/m2jean/ToothTray) (BSD-2) — подсмотрен механизм подключения: обход топологии аудиоустройства до KS-фильтра Bluetooth-драйвера и one-shot свойства `KSPROPSETID_BtAudio`. Код переписан на Rust, плюс добавлены выходы записи, чтобы отключался и Hands-Free.
- [StarTooth](https://github.com/slohmaier/StarTooth) (MIT) — трей-утилита для подключения сопряжённых Bluetooth-устройств, с которой всё началось. bt-toggle появился, когда мне не хватило трёх вещей: в моём сценарии наушники после отключения через StarTooth не подключались обратно ни из него, ни из Windows; список устройств приходилось обновлять вручную; не было заряда.
