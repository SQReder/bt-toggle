# bt-toggle

Утилита для Windows: подключать и отключать Bluetooth-наушники одним кликом по иконке в трее.

Сейчас это консольный прототип, который проверяет главный технический риск: подключение и отключение без поломки штатного переподключения Windows.

## Прототип

```powershell
cargo build
.\target\debug\bt-toggle.exe list                      # сопряжённые Bluetooth-аудиоустройства и их состояние
.\target\debug\bt-toggle.exe connect WH-1000XM4        # подстрока имени аудиовыхода
.\target\debug\bt-toggle.exe disconnect WH-1000XM4
```

Как это работает: для каждого аудиовыхода (воспроизведение и запись) утилита идёт по топологии устройства до KS-фильтра Bluetooth-драйвера (`bthenum` — A2DP, `bthhfenum` — Hands-Free). Затем шлёт ему `KSPROPERTY_ONESHOT_RECONNECT` / `KSPROPERTY_ONESHOT_DISCONNECT` из набора `KSPROPSETID_BtAudio`. Это тот же механизм, которым пользуется Windows. Подход взят из [ToothTray](https://github.com/m2jean/ToothTray) (BSD-2).

Проверено на Sony WH-1000XM4, Windows 11, 2026-10-14:

- `disconnect` переводит все аудиовыходы в `Unknown`, Windows показывает наушники отключёнными;
- после этого наушники подключаются и через `connect`, и штатно через Win+A;
- после `connect` воспроизведение продолжается на наушниках.

Подвох, найденный в тесте: Hands-Free может быть доступен только через выход записи (микрофон). Если перебирать одни выходы воспроизведения, как ToothTray, профиль HFP остаётся подключённым. Тогда звук пропадает, а Windows продолжает считать наушники подключёнными.

## MVP

1. Иконка в трее, левый клик подключает или отключает выбранное устройство.
2. Правый клик открывает меню: список сопряжённых аудиоустройств с галочкой на выбранном, «Запускать при входе», «Выход». Выбор запоминается.
3. Список обновляется сам, когда сопрягается новое устройство или удаляется старое.
4. У иконки три состояния: подключены / отключены / подключаюсь. В тултипе имя устройства и заряд в процентах.
5. Если подключиться не удалось, показывается тост Windows.

Вне MVP: хоткей, несколько избранных устройств, переключение устройства вывода звука, инсталлятор, подпись, winget.

Открытый вопрос: как читать заряд батареи. Нужно найти свойство устройства, которое показывают «Параметры → Bluetooth», образец — [BlueGauge](https://github.com/iKineticate/BlueGauge).
